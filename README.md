# S35-EA2-ManipulaciónArreglosListasenJava

## Pizza-Track

Aplicación de consola en Java para gestionar pedidos de una pizzería mediante arreglos y dos pilas manuales implementadas con listas enlazadas.

## Funcionalidades

- Registrar una pizza con nombre y tres ingredientes.
- Deshacer el último pedido registrado.
- Rehacer un pedido deshecho.
- Mostrar el pedido actual.

## Archivos principales

- `Pizza.java`: modelo de una pizza con un arreglo de ingredientes.
- `Pila.java`: implementación manual de una pila con nodos enlazados.
- `GestionPedidos.java`: lógica del menú y del flujo de pedidos.
- `Main.java`: punto de entrada de la aplicación.


## Ejecución

Requiere Java JDK instalado. Desde la carpeta del proyecto:

```bash
javac *.java
java Main
```

Los archivos compilados `.class` están excluidos del repositorio mediante `.gitignore`.
